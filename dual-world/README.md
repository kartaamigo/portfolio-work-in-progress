# Два мира · SoulArt / KRTY × RE: FORM

Интерактивный концепт сайта Марии Матвеевой. Собран для проверки идеи, до получения нового иллюстративного портфолио.

## Попробовать

На этом компьютере предпросмотр: http://127.0.0.1:8766

Для повторного запуска откройте `start-preview.cmd`. Требуется Python 3. Скрипт откроет сайт в браузере. Пока используете сайт, оставьте окно запуска открытым; закрытие останавливает предпросмотр.

## Поведение

- Слева SoulArt / KRTY: иллюстративный мир. Справа RE: FORM: 3D, светлый металл, стекло, розовый акцент и пиксельные детали.
- Наведение на текст выбора временно меняет первый экран. Фон и пустые области не переключают мир. Уход курсора с текста возвращает выбранный или нейтральный стиль.
- Нажатие закрепляет направление, меняет оформление всего сайта и прокручивает к содержимому.
- Прокрутка без выбора оставляет общую версию о Марии и двух направлениях.
- Переключатель в шапке доступен при прокрутке. Кнопка ◐ возвращает к нейтральному входу.
- На телефоне выбор работает по нажатию, без необходимости наведения.
- RE: FORM — прежде всего студия и проекты. Внутри: раздел студии, проекты, личные заметки и мини-сцена «Поймай идею».
- Мини-сцена: нажмите на светящийся пиксель. Заяц прыгает к нему, а этапы раскрывают процесс: идея, дизайн, код, ИИ, продукт. Работает мышью, касанием и кнопкой Enter при фокусе.
- Личные заметки сохраняются в браузере на этом устройстве. Они не отправляются автору и не синхронизируются. Удаление данных браузера удаляет заметки.

## Что пока черновое

Первый экран использует три предоставленных изображения: hero-neutral.jpg — без выбора, hero-art-v2.png — левая сторона SoulArt, hero-digital-animated.png — правая сторона RE: FORM. Переход между изображениями — горизонтальный сдвиг: SoulArt въезжает слева, RE: FORM справа; нажатие закрепляет направление. Использованы тексты и проекты из существующей локальной версии портфолио. Проект RE: FORM LIFE подписан как концепция.

Сайт работает локально, не опубликован. Ссылки контактов ведут к существующим аккаунтам из исходного портфолио. Контакт с автором требует перехода по ссылке, автоматической отправки нет.

Первый экран работает без WebGL. WebGL используется только в мини-сцене «Поймай идею». Шрифты загружаются с Google Fonts, без сети используются системные. Библиотека Three.js включена локально, её загрузка из интернета при просмотре не требуется.

## Проверка

Проверены наведение без фиксации, восстановление нейтральной версии, выбор направления, сохранение/удаление заметок, безопасный вывод текста, игра из пяти этапов и перезапуск. Проверены ширины 320, 390, 768 и 1440 пикселей во всех трёх режимах, горизонтального переполнения нет. Ошибок JavaScript в браузере не обнаружено.

В правом мире прозрачная композиция плавно покачивается и слегка следует за курсором. На сенсорном экране работает покачивание; при настройке уменьшения движения анимации отключаются.

Боковой переход плавный, без дымки и размытия. Заяц — неподвижный отдельный слой; анимка.png покачивается поверх него.

Текущая правая сцена собрана из исходной цельной картинки: digital-scene-base.jpg сохраняет зайца неподвижным, пять digital-prop-*.png анимируют отдельные периферийные предметы с разной скоростью.
